# Paid-command list v1, shared by the PreToolUse guards (#85).
# One rule per line, so adding a paid command is a one-line change.
#
# Line forms:
#   script:<name> :: <reason>            a pnpm run of that script name, or a
#                                       direct run of the file it runs
#   script:<name> && <ere> :: <reason>   that script, and the flag has to be
#                                       there too: one word starts with a
#                                       match of the ere
#   cmd:<ere> :: <reason>                anything else, matched against the
#                                       segment's text from its executable on
#   cmd:<ere> && <ere> :: <reason>       several conditions, all must hold
#   file:<path> :: <reason>              an Edit, Write or shell write to that
#                                       path is guarded
#
# A `script:` name is looked for as a token in a pnpm segment, so quoting and
# pnpm options (pnpm "generate-audio", pnpm run --silent generate-audio) do not
# hide it, and it has to be a real script name from package.json, which is what
# decision 1 asks for. A run of the file that package.json entry names, through
# tsx, node --import tsx, npx tsx or pnpm exec tsx, matches the rule too (#292).
# smoke-ingest is the exception: it has no package script, so it is matched as
# a run of scripts/smoke-ingest.ts (#671).

# ingest comes first, so a --from-step value that is also a script name
# (--from-step generate-audio) gets the ingest reason and not that script's.
script:ingest :: Paid: ingest resumes whatever steps are unfinished, and any of them can spend on Gemini, ElevenLabs credits or voice slots. Re-run it as LIVE_API_OK=1 pnpm ingest ... only if the task named that spend.
script:generate-audio :: Paid: generate-audio synthesizes the whole issue with ElevenLabs. Re-run it as LIVE_API_OK=1 pnpm generate-audio ... only if the task named that spend.
script:regenerate-timestamps :: Paid: regenerating timestamps re-calls ElevenLabs for every cue. Re-run it as LIVE_API_OK=1 pnpm regenerate-timestamps ... only if the task named that spend.
script:motion-comic :: Paid: motion-comic calls Gemini for the motion plan. Re-run it as LIVE_API_OK=1 pnpm motion-comic ... only if the task named that spend.
script:split-voice :: Paid: split-voice builds a new voice, which takes a voice slot. Re-run it as LIVE_API_OK=1 pnpm split-voice ... only if the task named that spend.
script:voice-rotation && --execute([^[:alnum:]_-]|$) :: Paid: --execute renames or deletes real ElevenLabs voices; without it every mode is a plan. Re-run it as LIVE_API_OK=1 pnpm voice-rotation ... only if the task named that spend.
script:voice-lab-import && --describe([^[:alnum:]_-]|$) :: Paid: --describe makes one Gemini call per voice lookup not stored yet. Re-run it as LIVE_API_OK=1 pnpm voice-lab-import ... only if the task named that spend.
script:voice-rotation-archive :: Paid: voice-rotation-archive renames and deletes real ElevenLabs voices. Re-run it as LIVE_API_OK=1 pnpm voice-rotation-archive ... only if the task named that spend.
script:voice-rotation-checkout :: Paid: voice-rotation-checkout renames and deletes real ElevenLabs voices. Re-run it as LIVE_API_OK=1 pnpm voice-rotation-checkout ... only if the task named that spend.
script:fix-page-watermarks :: Paid: fix-page-watermarks calls Gemini for every page it cleans. Re-run it as LIVE_API_OK=1 pnpm fix-page-watermarks ... only if the task named that spend.
script:recover-issue && --execute([^[:alnum:]_-]|$) :: Paid: recover-issue --execute stores every page through the watermark clean, one Gemini detect call per page and an image edit per overlay. Re-run it as LIVE_API_OK=1 pnpm recover-issue ... only if the task named that spend.
script:backfill-balloon-groups && (^|[[:space:]])--render([^[:alnum:]_-]|$) :: Paid: backfill-balloon-groups --render makes one ElevenLabs call per group. Re-run it as LIVE_API_OK=1 pnpm backfill-balloon-groups ... only if the task named that spend.
script:backfill-balloon-groups && (^|[[:space:]])--execute([^[:alnum:]_-]|$) :: Paid: backfill-balloon-groups --execute writes group_id on production bubble rows. Re-run it as LIVE_API_OK=1 pnpm backfill-balloon-groups ... only if the task named that write.
script:apply-fixes ::Paid: apply-fixes writes production rows. Re-run it as LIVE_API_OK=1 pnpm apply-fixes ... only if the task named that write.

# A GET is free, so this asks for two things at once: the host is ElevenLabs,
# and the method is not GET. The method is spelled out in character classes
# because macOS grep has no case-insensitive mode, and it allows -X, --request,
# an = separator, a quoted method and an attached value.
cmd:^([^[:space:]]*/)?curl[[:space:]].*api\.elevenlabs\.io &&.*(-[Xx][[:space:]]*=*[[:space:]]*[\"']?([Pp][Oo][Ss][Tt]|[Pp][Uu][Tt]|[Pp][Aa][Tt][Cc][Hh]|[Dd][Ee][Ll][Ee][Tt][Ee])|--request(=|[[:space:]]+)[\"']?([Pp][Oo][Ss][Tt]|[Pp][Uu][Tt]|[Pp][Aa][Tt][Cc][Hh]|[Dd][Ee][Ll][Ee][Tt][Ee])|(-[dFT][[:space:]\"']|-[dFT][^[:space:]]|--data|--form|--upload-file)) :: Paid: that is a write against the ElevenLabs API, not a GET. Re-run it as LIVE_API_OK=1 curl ... only if the task named that spend.

# The smoke run has no package script; it runs through pnpm exec tsx, and only
# --real makes it spend. A script: rule still covers a run of
# scripts/<name>.ts, so a grep for the flag or a quoted command line is no run.
script:smoke-ingest && --real([^[:alnum:]_-]|$) :: Paid: smoke-ingest --real runs the pipeline with real Gemini, ElevenLabs and Roboflow calls. Re-run it as LIVE_API_OK=1 pnpm exec tsx scripts/smoke-ingest.ts --real ... only if the task named that spend.

file:src/lib/voice-settings.ts :: Paid: this file holds the voice settings for paid synthesis. Edit it as CREDIT_OVERRIDE=1 only if the task named that spend.
file:src/lib/tts-request.ts :: Paid: this file builds the ElevenLabs TTS request. Edit it as CREDIT_OVERRIDE=1 only if the task named that spend.
