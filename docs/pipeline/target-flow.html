The prototype

Your question was whether starting at the editor misses things. The owner-facing flow is only three screens, so the prototype covers all three, shallow first, and goes deep on the editor. The machine steps between them have no screen to prototype.

1. Issue hub

one version

Where the run is, what is waiting for you, one button for the next thing. Replaces the colored links and the two start rules.

2. Characters

one version

A card per character in the style of your voice-lab reels grid: portrait, name, voice, status. Unknown clusters first.

3. Page editor

three variants: A, B, C

Tree on the left, page in the middle, the selected element's fields on the right. The variants differ in how you move through 300 bubbles fast.

Code, not Figma: a siloed route that reads the smoke issue read-only and keeps every edit in the browser. Clicks work, nothing writes to production, nothing is paid.
